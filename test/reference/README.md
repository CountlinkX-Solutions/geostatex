# Oracle fixtures

The fixtures under `fixtures/` are generated by the scripts in this directory with the reference
libraries (scikit-gstat, PyKrige and GSTools in Python, `gstat` in R) and committed. CI never runs
Python or R: the Elixir and Rust tests compare against the committed JSON.

```sh
uv venv .venv
uv pip install --python .venv/bin/python -r test/reference/requirements.txt
prlimit --as=3221225472 .venv/bin/python -I test/reference/generate_<name>.py
```

`common.py` holds the JSON conventions (deterministic output, non-finite floats as strings) and
the `meta` block of library versions every fixture carries. A generator never copies library
code: it only runs the libraries to record their results.

## R (`gstat`, from 0.4.0)

R `gstat` (GPL-2.0 or later) is a dev-time fixture generator only, as the Python libraries. It
lives in an environment outside the repository (so code indexers and tools never walk it),
installed without system packages from conda-forge with micromamba:

```sh
R_ENV=$HOME/.local/share/geostatex-r
mkdir -p $R_ENV/download
curl -fsSL https://micro.mamba.pm/api/micromamba/linux-64/latest -o $R_ENV/download/micromamba.tar.bz2
tar -xjf $R_ENV/download/micromamba.tar.bz2 -C $R_ENV bin/micromamba
MAMBA_ROOT_PREFIX=$R_ENV/root $R_ENV/bin/micromamba create -y -p $R_ENV/env \
  -c conda-forge --override-channels r-base r-gstat r-sp r-jsonlite
prlimit --as=3221225472 $R_ENV/env/bin/Rscript test/reference/generate_<name>.R
```

The R generators write JSON in the same layout as `common.py` (17 significant digits, a `meta`
block with the R and package versions), through `common.R`.
