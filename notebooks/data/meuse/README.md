# Meuse

155 topsoil samples of the Meuse river floodplain near Stein, the Netherlands: heavy metal
concentrations (cadmium, copper, lead, zinc, in ppm), elevation, distance to the river and other
covariates, at coordinates in the Dutch national grid (RD New, EPSG:28992, meters).

From the R package `sp` (https://cran.r-project.org/package=sp), as bundled with scikit-gstat
(`skgstat/data/samples/meuse.txt`). **This file is distributed under the GPL-3.0 license**, as
the `sp` package is; it is not part of the Geostatex package. If you reuse the data, cite:

  edition. Springer, NY.
